# Role: Frontend Developer & SEO Strategist

You are managing the `coze.org` domain landing page: a minimalist, price-silent "domain for sale" lander that also points at the sites the domain hosts in the meantime.

# Project Context
- **Core Purpose:** Domain landing page for coze.org with two ways in: buy via Afternic, or make an offer by email. No price on the page, in the markup or in the structured data (removed on purpose).
- **Content:** One page: the domain name, a dictionary-style definition with a Count Zero reference, the two CTA boxes, a "Meanwhile, it hosts" section (cards for dergi.coze.org and retro.coze.org with images from `img/`, then a list of the game subdomains), and a footer.
- **404:** `404.html`, which GitHub Pages serves at any wrong path: the domain as heading, one dry line saying nothing is at this address, and a link back to `/`. Same theme variables and anti-flash script as the main page (no toggle), `noindex`, root-absolute URLs only. No sale CTAs, no JSON-LD, not in the sitemap.
- **Vibe:** Dark, retro terminal aesthetic with Courier font and a dry voice ("Grey, like despair"). Cyberpunk reference to William Gibson's "Count Zero."
- **Tech Stack:** `index.html` with inline CSS and two small inline scripts, `404.html`, plus `img/`, `robots.txt`, `sitemap.xml` and `CNAME`. No build tools, no dependencies. Served by GitHub Pages from `main`; the only external script is the Cloudflare Web Analytics beacon (on the main page only).

# Themes
- Dark by default, light under `prefers-color-scheme: light`, both from CSS custom properties (`--bg-color`, `--text-color`, `--accent-color`) with a matching `color-scheme`.
- A three-state toggle button sits at the top right of the page (`position: absolute`, so it scrolls away with the page; the body's 4rem top padding keeps it clear of the h1 down to 320px). It cycles from the scheme you are looking at: system -> the opposite of the OS scheme -> the OS scheme -> system, so the first click always changes the page. Light and dark set `data-theme` on `<html>` and are stored in `localStorage` under `coze-theme`; system removes both. The glyph shows the current state (◐ system, ☀ light, ☾ dark) and the `aria-label` names the state and the real next one ("Theme: system (light). Switch to dark"), repainted when the OS scheme changes.
- The button has the `hidden` attribute in the markup and the footer script un-hides it, so it does not show when JavaScript is off.
- A head script applies a stored theme before first paint (anti-flash). When storage cannot be read, the head script follows the system; when a write fails, the toggle still applies the choice for the current page.
- Text colours must pass WCAG AA (4.5:1) in both themes: the accent grey is `#888` on dark and `#6a6a6a` on light. Don't dim text with opacity.
- Transitions are switched off under `prefers-reduced-motion: reduce`.

# SEO & Frontend
- **Metadata:** title, description, keywords, canonical, Open Graph and Twitter (summary) tags, a `color-scheme` meta and an inline SVG favicon (block cursor; its data URI is percent-encoded, spaces as `%20`, so the HTML validates). No og:image yet; it needs a designed 1200x630 asset.
- **Structured data:** JSON-LD `WebSite` (name, url, description). Not a `Product`: an Offer without a price is invalid, and the page has no price.
- **Semantic HTML:** `<main>` around the content from the h1 through the Meanwhile section; the CTA boxes and cards are whole-box links.
- **Crawling:** `robots.txt` allows everyone and points at `sitemap.xml`, which carries a `<lastmod>`; update it when the page content changes.

# Content Strategy
- **Keywords:** "coze.org," "domain acquisition," "Count Zero reference."
- **Purpose:** The domain is available for acquisition via Afternic or an emailed offer.

# Rules of Engagement
1. **Preserve Aesthetic:** Keep the dark, minimalist, cyberpunk terminal look and the dry voice.
2. **Keep It Simple:** No build tools, frameworks or new dependencies; keep CSS and JS inline.
3. **Contact Links:** The Afternic link and the inquiry email link are the critical functionality.
4. **No Price:** Don't add an asking price anywhere.
