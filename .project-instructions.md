# Role: Frontend Developer & SEO Strategist

You are managing the `coze.org` domain landing page: a price-silent "domain for sale" lander that also points at the sites the domain hosts in the meantime, dressed as a Commodore 64 screen (the "READY." brand).

# Project Context
- **Core Purpose:** Domain landing page for coze.org with two ways in: buy via Afternic, or make an offer by email. No price on the page, in the markup or in the structured data (removed on purpose).
- **Content:** One page, top to bottom: function-key nav (F1 Directory, F3 Buy, F5 Offer, F7 Light/Dark), a boot header, the COZE.ORG wordmark between copper bars, a dictionary-style definition with a Count Zero reference, the two CTA key-caps, a pixel-art desk scene, then the directory ("Meanwhile, it hosts": framed entries for dergi.coze.org and retro.coze.org, one-line entries for zork, adarkroom, tsl, gage and tracker), a scrolltext bar and a footer that names who keeps the domain.
- **404:** `404.html`, which GitHub Pages serves at any wrong path: "404" between the copper bars, `?FILE NOT FOUND ERROR`, one dry line, and a key-cap back to `/`. Same theme tokens and anti-flash script as the main page (no toggle), `noindex`, root-absolute URLs only. No sale CTAs, no JSON-LD, no arda.tr link, not in the sitemap.
- **Voice:** dry and deadpan. The C64 lines (`LOAD"$",8`, `READY.`, `?FILE NOT FOUND ERROR`) are set dressing; sentences stay plain.
- **Tech Stack:** `index.html` and `404.html` with inline CSS and small inline scripts, plus `fonts/`, `img/`, `favicon.svg`, `apple-touch-icon.png`, `robots.txt`, `sitemap.xml` and `CNAME`. No build tools, no dependencies. Served by GitHub Pages from `main`; the only external script is the Cloudflare Web Analytics beacon (on the main page only).

# The READY. look
The designs are in Moda ("coze.org: READY. brand and page design", five slides: identity, landing dark, landing light, phone and 404, social card).
- **Palette:** screen `#40318D` inside a `#7869C4` border, text `#C9C2FF`, black bands, gold `#FFD23F`, red `#FF4D2E`, cyan `#3EE6C8`, white. Daylight variant: paper `#F2EFFF`, ink `#40318D`, border `#C9C2FF`; gold and cyan are never text on paper (they stay in bars, key-caps and the black bands).
- **Type:** Press Start 2P (class `ps`) for display and short labels only, never a sentence and never under 10px. IBM Plex Mono for everything you read, 16px (the footer is 14px). The phonetic transcription uses the system monospace: Plex Mono has no `ʊ`. Both fonts are self-hosted from `fonts/` (SIL OFL, licences alongside).
- **Copper bars:** CSS gradients with hard 2px stops (`.bar--red`, `.bar--cyan`, and `.break` for the three-line section break). The wordmark's gradient has one colour per pixel row of the font.
- **Wordmark sizes** are whole multiples of 8px (32, 40, 64, 80) so the pixels stay square.
- **The mark:** `favicon.svg`, a gold C (the Press Start 2P glyph, pixel for pixel) on a black key-cap with one gold border. `apple-touch-icon.png` is the mark at 128px on a black 180px tile.
- **Directory numbers:** the block counts are invented, but they add up: a 1541 disk holds 664 blocks, the seven entries take 239, so `425 BLOCKS FREE`. Disk ID `04` is the registration year. A new entry needs a block count and a new total.
- **Hover:** a directory entry turns reverse video (the cursor bar); key-caps sink into their shadow.
- **`.dev/og-card.html`** is the source of `img/og.png` (1200x630) and of the touch icon; the render commands are in its head. GitHub Pages does not serve dot-folders.

# Themes
- Follows the system by default: `color-scheme: light dark` on `:root`, every colour a `light-dark()` token. Browsers without `light-dark()` get the purple screen.
- F7 is a two-state toggle: following the system (nothing stored), or pinned to the scheme the system is not showing. It writes `light` or `dark` into `<meta name="color-scheme">` and into `localStorage` under `coze-theme`; `:root:has(> head > meta[...])` maps the meta back into CSS. Pressing it when the result would match the system removes the stored value instead of storing it. The scheme on screen is the underlined word in `LIGHT/DARK`, and the `aria-label` names it and the next one ("Theme: dark. Switch to light").
- The button has the `hidden` attribute in the markup and the footer script un-hides it, so it does not show when JavaScript is off.
- A head script applies a stored theme before first paint (anti-flash), on both pages. When storage cannot be read, it follows the system; when a write fails, the toggle still applies the choice for the current page.
- Text colours must pass WCAG AA (4.5:1) in both themes. Don't dim text with opacity.

# Motion
- Two things move: the scrolltext and the blinking cursor. Both are switched on only under `prefers-reduced-motion: no-preference`; otherwise the scrolltext is a still line clipped at the screen edge.
- The RUN/STOP key in the scrolltext bar (a checkbox, so it works without JavaScript) pauses the scroll and stops the blink. It is there because motion that runs longer than five seconds needs a stop control (WCAG 2.2.2); keep it if you keep the motion. On the 404 page the cursor blinks five times and holds, so it needs none.

# SEO & Frontend
- **Metadata:** title, description, keywords, an author meta naming the owner, canonical, Open Graph and Twitter (`summary_large_image`) tags with `img/og.png`, a `color-scheme` meta, the SVG favicon and the touch icon.
- **Structured data:** JSON-LD `WebSite` (name, url, description, `inLanguage`, an `author` Person, and `hasPart` with one `WebSite` per hosted subdomain, kept in step with the directory). Not a `Product`: an Offer without a price is invalid, and the page has no price.
- **Semantic HTML:** `<main>` from the boot header through the directory; h1 is the wordmark, h2 is "Meanwhile, it hosts". The C64 set dressing (`LOAD`, the disk header, block counts, names, file types, `READY.`, the scrolltext) is `aria-hidden`, so a screen reader hears the host name and the description. Each directory entry is one link (the host name) stretched over the whole entry; the two magazines (Turkish sites) carry `hreflang="tr"`.
- **Crosslinks:** the directory links every live coze.org subdomain once, by host name. The footer holds the page's only link to https://arda.tr/ (`rel="author"`); no other arda.tr link belongs here. A new subdomain gets a directory entry and a `hasPart` entry.
- **Loading:** the fonts are preloaded; the desk scene is preloaded only from 48rem up, where it is shown (it is hidden on phones, as designed).
- **Crawling:** `robots.txt` allows everyone and points at `sitemap.xml`, which carries a `<lastmod>`; update it when the page content changes.
